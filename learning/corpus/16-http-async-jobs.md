# DOC-16：异步任务接口

提交接口先校验、鉴权和检查容量，持久化接受的任务后返回 202 与任务 ID。客户端通过任务查询接口轮询状态，直到成功或失败。任务 ID 只是查询标识，不能证明计算已经成功。

教学状态为 queued、running、succeeded、failed。队列长度有上限，满时拒绝新请求；任务到截止时间应转为失败，避免永久 running。总耗时包括排队和执行，应在接受时确定截止时间。

单实例重启时，恢复尚可执行且未过期的 queued 任务，把先前 running 任务标记失败，允许用户重新提交。终态不能被晚到结果覆盖。轮询应有间隔与停止条件，不能无限高频查询。

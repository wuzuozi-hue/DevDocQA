# DOC-30：评测与结果边界

教学题集分 dev 与 test：dev 用于调试和选择参数，test 在配置固定后测量。若反复根据 test 错误调参，test 就不再是独立检验，需要新的未使用测试集。

文档级 Hit@5 检查前五召回片段是否覆盖期望来源；本题集 direct 要命中期望文档，multi_document 要覆盖全部期望文档。可回答题测召回与人工正确率，无答案题单独测依据不足识别率。引用支持程度也独立记录。

Mock 仅验证任务流程和固定延迟负载，不能用来测真实模型问答正确率。真实模型报告需保存模型、配置、环境、数据和原始输出。此原创教学题集很小且简单，不是行业 benchmark，也不代表生产效果。
